# Bring Dimitrii To Home: Luperon

2D-симулятор динги (небольшой надувной лодки) на **Godot 4.7** (GDScript, рендерер
Compatibility). Экипаж перевозится от яхты к доку и обратно, с объездом препятствий
и буксировкой заглохших динги. Каждая "версия" игры — отдельный самодостаточный мир;
текущая — залив **Luperón**.

Это стартовый каркас: запускаемый проект + обвязка репозитория. Геймплей наполняется
поверх него.

## Что уже работает

- Управляемая динги как `RigidBody2D` без гравитации; "вода" — сопротивление,
  разное вдоль и поперёк корпуса (лодка не скользит боком в поворотах), вращение
  гасит `angular_damp`. Тяга вдоль носа, руль эффективен на ходу.
- Мир залива: вода, береговая линия, док и пришвартованные лодки-препятствия
  (статичные тела с коллизией).
- Портретная ориентация; камера держит лодку носом вверх и поворачивается за
  курсом с небольшой инерцией (немного отстаёт в поворотах).
- Кильватерный след: V от носа под углом Кельвина (~19.5 град) и струя от
  винта по оси за кормой, из затухающих прямоугольников, не длиннее трёх
  длин лодки; расстояние между метками показывает скорость.
- Буксировка: подойти кормой к носу заглохшей динги (вокруг него появится
  кольцо) и нажать Space / E — трос `TowRope` подцеплен; то же нажатие
  отдаёт трос. Трос только тянет, провисает при сближении, прицеп идёт в
  кильватере.
- Строгая типизация GDScript: нетипизированные объявления и небезопасный доступ
  к свойствам/методам — ошибки (`project.godot`, секция `[debug]`).

**Управление:** WASD или стрелки; Space / E — зацепить / отдать трос.

```

├── project.godot              # манифест проекта (input map, рендерер, окно)

│   ├── world/luperon.tscn     # главная сцена (мир залива)

│   ├── world/follow_camera.gd # камера по курсу лодки с инерцией

│   ├── actors/tow_rope.gd     # буксирный трос
│   └── effects/wake_trail.gd  # след за лодкой
├── assets/                    # sprites / audio / fonts (пока пусто)
├── addons/                    # сюда лягут GDExtension (напр. физика троса)

├── .vscode/                   # launch.json / settings.json / extensions.json
├── .github/workflows/ci.yml   # headless import + smoke-run
└── SETUP.md                   # настройка машины и отладки (включая деплой на телефон)
```

## Как запустить

1. Открыть папку проекта в **Godot 4.7** (File → Open Project, выбрать `project.godot`).
   При первом открытии движок импортирует ассеты и создаст папку `.godot/`
   (она в `.gitignore`).
2. Нажать **F5** — запустится `scenes/world/luperon.tscn`.

Отладка из VS Code и деплой на Android-телефон описаны в **SETUP.md** (конфиг
`.vscode/launch.json` уже в репозитории; поправьте только путь к `godot.exe`
в `.vscode/settings.json`).

## Git

`.gitattributes` держит текстовые файлы (включая `.tscn`) в LF — на Windows
дополнительно: `git config --global core.autocrlf input`.

Файлы `*.uid` и `*.import`, которые создаёт редактор, коммитятся: в них
стабильные идентификаторы ресурсов, на которые ссылаются сцены.

## Ближайшие шаги

1. Цель уровня: доставка/буксировка к нужной яхте (сигналы `hooked` /
   `released` у `TowRope` уже есть).
2. Мобильное управление: виртуальный стик и кнопка зацепа.
3. Модель воды и столкновений (сопротивление, инерция, мягкие удары о причал),
   руль подвесного мотора.

## CI

`ci.yml` на каждый push/PR импортирует проект и запускает главную сцену headless,
падая при ошибках скриптов/парсинга. Экспортных шаблонов не требует. Упаковка
сборок (desktop/Android) — закомментированный раздел в том же файле.
